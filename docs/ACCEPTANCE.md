## 已知偏差：高难度格子尺寸

PRD 要求 16×30 棋盘格子最小可点击尺寸 ≥28–30px。物理上 16 列在 375–390pt 宽屏幕无法在保留边距的同时达到该值：

- 390×844：16×16 约 20.8pt/格；16×30 约 17.9pt/格。
- 375×667：16×30 约 13–14pt/格（高度受限）。
- 以上为 v1.1 含底部缩放条的实测；放大后约 56pt/格。
- 当前策略：优先压缩格间距到 1–2pt，再按屏幕适配，格子不继续缩小到不可读；坐标映射按实际格子矩形判定。
- **v1.1 已加入“放大 + 平移”**：底部缩放条（`−/%/+/适应`）+ 双指捏合；放大后单指拖动查看；缩放条在棋盘下方，不遮挡格子。100% 仍受物理尺寸限制，但玩家可放大到约 56pt/格，解决高难度点击困难。该偏差已记录在 [PRD §14.1](PRD.md#14-实现判定与偏差记录开发基线补充)。
